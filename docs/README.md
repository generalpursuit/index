# Guides

These guides cover contracts shared by clients and repeatable operations. Endpoint fields come from generated OpenAPI, and implementation details stay with their source.

- [API](api.md): transports, visibility, pagination and messaging.
- [Authentication](authentication.md): signed sessions, verification and account isolation.
- [Readable routes](readable-routes.md): canonical URLs, aliases and access checks.
- [Data loading](data-loading.md): caching, placeholders, instant edits and freshness on every client.
- [Sharing](sharing.md): duplicate saves, retry receipts and native credential boundaries.
- [Notifications](notifications.md): delivery privacy, providers and operations.
- [Deployment](deployment.md): environments, migrations and recovery.
- [Desktop releases](desktop-releases.md): channels, publication and update recovery.
- [README screenshots](screenshots.md): capturing and composing the README's product images.

Development owners: [web and desktop](../apps/web/README.md), [iOS](../apps/ios/README.md), [brand artwork and generation](../assets/brand/README.md). Start with the root [README](../README.md) for common commands and [AGENTS](../AGENTS.md) for the repository map.
